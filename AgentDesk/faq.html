租之前，
先把问题问清楚。

关于设备、网络、AI 工具、付款和出租的常见疑问。没找到答案，可以直接发布求租或联系我们。

待确认标出的内容是原型里的业务假设，上线前需要确认或修改，确认后删掉标记即可。

租到的是虚拟机吗？会和别人共用吗？

不是虚拟机。官方直营的每个方案都对应一台实体电脑，租期内整机只给你一个人用，不超售。个人直租的设备由机主提供，独享方式写在设备页上，租之前请再核对一次。

机器放在哪里？

官方直营设备在马来西亚吉隆坡，个人直租的设备分布在槟城、新加坡等城市。每台设备的国家和城市都写在设备页和交付信息里。

住宅 IP 是固定的吗？是我一个人用吗？待确认

官方直营设备的住宅 IP 在租期内保持不变，运营商如有调整会提前通知你。家庭宽带不等于每台电脑都有独立的出口 IP：是独享还是和同一条线路上的机器共用，设备页会单独写明。

从中国连过去，延迟大概多少？

以吉隆坡为例，深圳、广州约 40–50 ms，上海、杭州约 65–70 ms，北京约 85 ms，实际取决于你的运营商和时段。远程桌面能感觉到一点；在终端里配合 tmux 或 mosh，几乎感觉不到。每台设备页有最近 7 天的实测值，付款前也可以申请连接测试。

机器会一直开着吗？停电怎么办？

会。我们关闭了自动睡眠，配了 UPS，并设置为来电后自动开机。计划内的系统更新会提前通知你；硬件故障由当地运维到现场处理。

为什么选吉隆坡？

吉隆坡和北京同为 UTC+8，不用换算时间；到华南约 40 ms、到华北约 85 ms（示例数据）；当地家庭光纤普及，可选的运营商也多。缺点是离华北比华南远，对延迟特别敏感的远程桌面操作，建议先申请一次连接测试。

带宽有限制吗？能一直跑满吗？待确认

每台设备的下行和上行写在设备页上。正常使用不限流量，但不能长时间跑满上行，例如做下载站或对外提供服务，这会影响同一条线路上的其他使用。

机器坏了，多久能修好？待确认

远程能处理的（重启、网络恢复）随时可以申请。需要到现场的，当地运维通常 24 小时内修复或换机；超过 48 小时仍无法使用，可以提前终止并按天退还剩余租金。你自己那边的网络问题不在此列。

nanoMuse 是你们的产品吗？

不是。nanoMuse 是独立的开源社区项目，我们提供的是能让它长期运行的电脑，也可以帮你预装。它的功能和更新以 nanomuse.cn 官方文档为准。

可以跑 Codex、Claude Code 这类 AI 编程工具吗？

可以，它们和在你自己的电脑上一样运行。AI 服务的账号由你自己注册、付费和管理，请遵守各服务的条款和使用地区规定；设备在哪里，不代表你因此获得某项服务的使用资格。

你们提供 Claude、ChatGPT 等账号吗？

不提供，也不代开、不代管任何第三方账号或订阅，更不提供共享账号。租金只包含设备和网络。

能保证某个 AI 服务一直能用吗？

不能。我们负责让机器和网络稳定在线；第三方服务是否可用、如何管理账号，由服务方自己决定，我们无法对此做任何承诺。

用住宅 IP 就不会被封号了吗？

不能这么保证。住宅 IP 更接近普通用户，但每个平台怎么判断风险，由平台自己决定。请用自己的账号、遵守平台条款，不要在同一台机器上频繁切换大量账号。

租到之后怎么连上？待确认

交付信息里会给出连接方式，默认推荐 UU 远程；也可以用 UU 终端、SSH / mosh、VS Code Web，或使用每台机器的 Cloudflare 固定专属地址在浏览器里登录。Tailscale、ToDesk、RustDesk 可以在进入桌面后自己配置。

有管理员权限吗？能自己装软件吗？

有完整的管理员权限，想装什么软件和开发环境都可以。Homebrew、Git、Node.js、Python、Docker 等常用工具可以预装；Xcode、Final Cut Pro 等需要你用自己的 Apple 账户下载或购买。

你们会看我的数据吗？

不会录屏，不记录按键，日常运营也不浏览你的文件。需要进入你的环境维护时，会先征得你同意并保留操作记录；机器失去响应时，只检查供电、网络或重启，不借此读取文件。

数据会备份吗？退租后怎么处理？待确认

机器上的数据请自己备份，重要代码及时推送到你自己的仓库。退租后我们会抹除整块硬盘并重装系统，再交给下一位租客。

可以几个人一起用一台吗？

一台机器对应一位客户。团队里多个人要用，建议每人一台；如有特殊需要，请在下单前说明。连接权限不能转租或转卖。

能用来做代理、VPN 或转售网络吗？待确认

不能。出租的是电脑和它所在的网络，不能把线路转售成代理或 VPN，也不能用来群发、扫描、攻击或挖矿。收到运营商投诉会先警告一次，再次发生会停用且不退款。

需要用我的 Apple ID 吗？

我们不会要你的 Apple ID。建议用一个单独的 Apple ID 登录，不要开启「查找」，退租前记得退出登录，否则抹盘重装会受影响。

硬盘有加密吗？待确认

为了停电恢复后能自动登录、远程工具能自动连上，FileVault 默认关闭。如果你更在意磁盘加密，可以自己开启，但之后每次停电或重启，都需要运维到现场输入密码才能连上。

付款后多久能用上？待确认

官方直营的现货设备，付款后 2 小时内把连接信息发到你的邮箱。个人直租的设备以设备页标注的交付时间为准。

怎么付款？能开发票吗？

在线下单付款，支持按月、季、年付，可用的付款方式以付款页为准。需要发票或报销凭证的，请在下单前说明。

怎么续租、停用？能退款吗？待确认

到期前可以一键续租；不续租的话到期自动停用，没有押金。交付后如果因为我们的原因无法正常使用，可以申请全额退款，其他情况以服务条款为准。

租到一半想升级配置可以吗？待确认

可以。差价按剩余天数计算，数据迁移由我们协助完成。

设备归谁？能买断吗？待确认

官方直营的设备归平台，托管出租和个人直租的设备归房东，目前不提供买断。

客服什么时候在线？待确认

工作日 10:00–22:00（北京时间）在线；机器失联、连不上这类紧急问题全天处理。

托管出租和个人直租有什么区别？

都是你的机器放在你家。托管出租由平台定价、收款和交付，你每月拿租金扣掉固定的平台服务费；个人直租由你自己定价、收款、和租客沟通、自己交付。看对比

托管的机器掉线了怎么办？待确认

超过 15 分钟没有心跳，你会收到通知，请尽快到场处理；掉线期间租客的服务期顺延，顺延的天数不计收入。

我能看到租客的信息吗？

托管出租看不到：租客的姓名和联系方式只在平台这边，你也不接触租客机器里的数据。需要你进入租客环境处理问题时，我们会先征得租客同意。

电费网费谁出？可以退出吗？

机器、电费和网费由你承担。不想继续了，在后台把空闲的机器设为维护，就不再接新租客；在租的租客照常服务到期，已经服务的天数照常结算。

发布出租或求租要收费吗？

发布免费。出租帖和求租帖都要先审核，通过后才会公开展示，成交前请双方确认实际配置、网络和交付安排。

个人直租的设备你们核验过吗？待确认

上架前我们会审核设备信息，并做一次连接测试。但配置、所在地和网络以机主填写为主，审核不等于担保，付款前请再次和机主确认。

登记之后能保证有租客、有收入吗？

不能保证。出租快慢取决于设备、地区、价格和需求；没有租客时不会产生租金收入。
