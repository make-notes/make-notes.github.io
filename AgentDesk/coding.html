让 Agent 无人值守

交付时做好的，
和建议你自己设置的。

交付时已经做好

  • 关闭自动睡眠，来电后自动开机，配 UPS
  • Homebrew、Git、Node.js、Python、Docker 等常用环境
  • tmux 和 mosh，断线不丢会话
  • 远程登录方式已配置好，交付邮件里写明怎么连

建议你自己设置

  • 在 tmux 里启动 Agent，关掉终端它也继续跑
  • 给 Codex、Claude Code 配好权限规则：哪些命令可以直接执行，哪些要先问你
  • 多个任务并行时，用 git worktree 给每个 Agent 一份独立的工作目录
  • 密钥放在环境变量或钥匙串里，不要写进代码和提示词
  • 用 claude -p 或 codex exec 写定时任务，结果推送到手机

第一次登录后

  1. 改掉初始密码交付邮件里的密码只用一次，不要转发。
  2. 设置 Git 身份和 SSH 密钥生成 ed25519 密钥，加到 GitHub 或你自己的代码仓库。
  3. 登录你自己的 Agent 账号Codex、Claude Code 用你自己注册和付费的账号，推一次代码确认一切正常。

我们不提供、不代管任何 AI 服务的账号，也不是代理服务。设备在哪里，不代表你因此获得某项服务的使用资格，请遵守各服务的条款和使用地区规定。
