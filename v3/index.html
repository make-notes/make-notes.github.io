01 个人 / 生活 Agent

nanoMuse 记住你，
把生活里的事替你做完。

nanoMuse 是一个开源的个人 Agent。它记得你的目标，在后台一步步推进；事情发生时自动开工；还能跨手机和电脑操作应用，把结果做成文件交给你。同一个账号覆盖手机、电脑和网页，看到的是同样的对话。

nanoMuse开源个人 Agent · GPL-3.0 官网 nanomuse.cn ↗ 文档 ↗ GitHub ↗

你可以这样跟它说

三个月后去日本，帮我一步步准备长期目标 · 主动推进

它把目标拆成步骤，在后台隔一段时间推进一步：比价机票、列出签证材料。每周一跟你同步进度；计划不再合适时，它会提出修改，由你决定用不用。

找到手机上的外卖订单号，填进电脑上的报销表跨设备 · 一句话

手机上的 nanoMuse 通过屏幕找到订单号，电脑上的 nanoMuse 把它写进表格。两台设备各做一半，过程都在你发消息的那段对话里。

标题带“评审”的会议，提前半小时给我一页简报触发器

不是到点提醒，而是事情发生时自动开工：日程开始前、收到某封邮件、某台设备上线，或者你的部署脚本调用它的时候。

每天帮我盯着骑行和 Rust 的新动态，每周推荐一道菜Feed · 为你写的内容

每天按你的要求、目标和它对你的了解写三条短帖。你不在的时候它做了什么，回来在“你不在时”里一眼就能看到。

这三家保险方案帮我比一下，做成表技能 · 产出文件

查资料、整理对比，生成表格或网页存进文件库，在手机上直接打开。不只是回一段话，而是给你一个能用的结果。

记住：我对花生过敏，安排吃饭时避开记忆 · 归你所有

之后帮你订餐、做行程都会考虑这一点。它记住的每一条你都能看到、修改和删除，删掉的它不会再用。

记住你
每条记忆都能查看、修改、删除；它会定期合并整理，每次改动都能撤销。关于你的设定写在可以直接阅读的 Markdown 文件里。
安排
长期目标拆成步骤，在后台推进、按时跟进；提醒、定时任务和触发器；可以订阅你的日历 （只读，它不会直接改你的日历）；设置安静时段，夜里不打扰。
动手
终端、浏览器、MCP 连接器（Notion、GitHub、Linear 等常用服务）和 Agent Skills，开启 Hands 后可以操作屏幕。
守门
每一次工具调用都要经过 Sentinel 检查：删除、发送、付款这类敏感操作先问你，超时没回应就当作拒绝。
模型
用你自己的 Key：DeepSeek、Kimi、通义百炼、智谱 GLM、豆包、OpenAI、OpenRouter、Ollama 等。也可以登录社区中继，用免费额度。中继可以自己部署。

为什么放在一台常开的电脑上

电脑睡着了，nanoMuse 也就停了。

推进目标、触发器、定时任务和每天的 Feed，都由正在运行的 nanoMuse 发起。家里的笔记本一合盖，这些就都停了，错过的只会在开机后补跑一次。放在一台 24 小时在线的电脑上，它才真的一直在替你做事。

13:30评审会前半小时，简报已就绪
23:40笔记本合盖：后台工作全部暂停

nanoMuse 是独立的开源社区项目（GPL-3.0-or-later），不是本平台的产品。各客户端能力不完全相同，例如 iPhone 不支持操作屏幕，Linux 的屏幕操作只支持 X11，Windows 的屏幕操作仍在测试。一切以 nanomuse.cn 官方文档为准。

稳定的家庭 IP，

每台设备接的都是当地真实的家庭宽带，用的是运营商分配给住户的 IP。我们把线路、IP 类型、城市和延迟写清楚，你自己判断适不适合。

  • 更容易遇到验证码
远桌家庭宽带住宅 IP198.51.100.x
  • 运营商分配
  • 租期内固定
  • 消费级路由器
  • 真实家庭网络

为什么更适合用 AI

不少网站和 AI 服务会把机房 IP 当作服务器流量，更容易出现验证码、二次验证或功能限制。住宅 IP 更接近普通用户，登录地点长期不变，适合一直挂着的 Agent 和 AI 工具。

为什么要稳定

IP 经常变，账号就会不停地被要求重新验证。租期内 IP 不变，如果运营商调整，我们会提前通知你。

10 常见问题

租之前，
先把问题问清楚。

关于设备、网络、AI 工具、付款和出租的常见疑问。没找到答案，可以直接发布求租或联系我们。

待确认标出的内容是原型里的业务假设，上线前需要确认或修改，确认后删掉标记即可。

租到的是虚拟机吗？会和别人共用吗？

不是虚拟机。官方自营的每个方案都对应一台实体电脑，租期内整机只给你一个人用，不超售。第三方设备由机主提供，独享方式写在设备页上，租之前请再核对一次。

机器放在哪里？

官方自营设备在马来西亚吉隆坡，第三方设备分布在槟城、新加坡等城市。每台设备的国家和城市都写在设备页和交付信息里。

住宅 IP 是固定的吗？是我一个人用吗？待确认

官方自营设备的住宅 IP 在租期内保持不变，运营商如有调整会提前通知你。家庭宽带不等于每台电脑都有独立的出口 IP：是独享还是和同一条线路上的机器共用，设备页会单独写明。

从中国连过去，延迟大概多少？

以吉隆坡为例，深圳、广州约 40–50 ms，上海、杭州约 65–70 ms，北京约 85 ms，实际取决于你的运营商和时段。远程桌面能感觉到一点；在终端里配合 tmux 或 mosh，几乎感觉不到。每台设备页有最近 7 天的实测值，付款前也可以申请连接测试。

机器会一直开着吗？停电怎么办？

会。我们关闭了自动睡眠，配了 UPS，并设置为来电后自动开机。计划内的系统更新会提前通知你；硬件故障由当地运维到现场处理。

nanoMuse 是你们的产品吗？

不是。nanoMuse 是独立的开源社区项目，我们提供的是能让它长期运行的电脑，也可以帮你预装。它的功能和更新以 nanomuse.cn 官方文档为准。

可以跑 Codex、Claude Code 这类 AI 编程工具吗？

可以，它们和在你自己的电脑上一样运行。AI 服务的账号由你自己注册、付费和管理，请遵守各服务的条款和使用地区规定；设备在哪里，不代表你因此获得某项服务的使用资格。

你们提供 Claude、ChatGPT 等账号吗？

不提供，也不代开、不代管任何第三方账号或订阅，更不提供共享账号。租金只包含设备和网络。

能保证某个 AI 服务一直能用吗？

不能。我们负责让机器和网络稳定在线；第三方服务是否可用、如何管理账号，由服务方自己决定，我们无法对此做任何承诺。

租到之后怎么连上？待确认

交付信息里会给出连接方式，默认推荐 UU 远程；也可以用 UU 终端、SSH / mosh、VS Code Web，或使用每台机器的 Cloudflare 固定专属地址在浏览器里登录。Tailscale、ToDesk、RustDesk 可以在进入桌面后自己配置。

有管理员权限吗？能自己装软件吗？

有完整的管理员权限，想装什么软件和开发环境都可以。Homebrew、Git、Node.js、Python、Docker 等常用工具可以预装；Xcode、Final Cut Pro 等需要你用自己的 Apple 账户下载或购买。

你们会看我的数据吗？

不会录屏，不记录按键，日常运营也不浏览你的文件。需要进入你的环境维护时，会先征得你同意并保留操作记录；机器失去响应时，只检查供电、网络或重启，不借此读取文件。

数据会备份吗？退租后怎么处理？待确认

机器上的数据请自己备份，重要代码及时推送到你自己的仓库。退租后我们会抹除整块硬盘并重装系统，再交给下一位租客。

可以几个人一起用一台吗？

一台机器对应一位客户。团队里多个人要用，建议每人一台；如有特殊需要，请在下单前说明。连接权限不能转租或转卖。

付款后多久能用上？待确认

官方自营的现货设备，付款后 2 小时内把连接信息发到你的邮箱。第三方设备以设备页标注的交付时间为准。

怎么付款？能开发票吗？

在线下单付款，支持按月、季、年付，可用的付款方式以付款页为准。需要发票或报销凭证的，请在下单前说明。

怎么续租、停用？能退款吗？待确认

到期前可以一键续租；不续租的话到期自动停用，没有押金。交付后如果因为我们的原因无法正常使用，可以申请全额退款，其他情况以服务条款为准。

租到一半想升级配置可以吗？待确认

可以。差价按剩余天数计算，数据迁移由我们协助完成。

发布出租或求租要收费吗？

发布免费。出租帖和求租帖都要先审核，通过后才会公开展示，成交前请双方确认实际配置、网络和交付安排。

第三方设备你们核验过吗？待确认

上架前我们会审核设备信息，并做一次连接测试。但配置、所在地和网络以机主填写为主，审核不等于担保，付款前请再次和机主确认。

房东合作和自己发布出租有什么区别？待确认

自己发布出租，你负责定价、沟通和交付。房东合作是你提供设备、电和家庭宽带，当地运维上门安装和巡检，平台负责招租、交付和日常维护，按租金分成，比例在合作前写明。

登记之后能保证有租客、有收入吗？

不能保证。出租快慢取决于设备、地区、价格和需求；没有租客时不会产生租金收入。
